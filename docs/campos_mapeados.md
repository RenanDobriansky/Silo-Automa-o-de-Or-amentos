# Campos Mapeados

## Cabecalho da ordem

- `pedido` -> numero da ordem de compra
- `fornecedor` -> nome do fornecedor
- `cnpj` -> documento do fornecedor
- `data_entrega` -> data prevista de entrega

## Itens

- `codigo` -> codigo original do item
- `codigo_neogrid` -> codigo final apos de-para
- `descricao` -> descricao do item
- `quantidade` -> quantidade comprada
- `unidade` -> unidade comercial
- `preco_unitario` -> valor unitario do item

## Planilha de apoio

Colunas minimas esperadas:

- `codigo_origem`
- `codigo_neogrid`

Colunas opcionais:

- `descricao_neogrid`
- `similaridade`
- `observacao`
